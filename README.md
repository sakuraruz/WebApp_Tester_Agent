# WebApp Tester Agent

Агент-тестировщик веб-приложений для VS Code (custom agent в Copilot + Playwright MCP).
Лабораторная работа 2 по дисциплине «Технологии разработки программного обеспечения».

Исполнители: Рузина В., Лебедевич К., Корнеев М., Цомаева Д., Волосков А.

## Назначение

Агент открывает веб-приложение в браузере, выполняет действия пользователя, проверяет консоль и сетевые запросы и сохраняет отчёт об ошибках с рекомендациями. Ускоряет и дополняет ручное тестирование, но не заменяет его.

## Состав ветки `testWebbApp`

| Путь | Назначение |
|---|---|
| `.github/` | файл агента (`.agent.md`) |
| `.mcp.json` | подключение Playwright MCP |
| `server.js`, `public/`, `package.json` | тестовое веб-приложение (Node.js, Express) со ссылкой «Забыли пароль?», ведущей на несуществующий маршрут |
| `reports/` | отчёты агента (создаются при прогоне) |

## Требования

- VS Code с GitHub Copilot (выполнен вход в аккаунт)
- Node.js (для запуска Playwright MCP через `npx`)

## Запуск

1. Клонировать ветку и установить зависимости:
   ```bash
   git clone -b testWebbApp --single-branch https://github.com/sakuraruz/WebApp_Tester_Agent.git testWebbApp
   cd testWebbApp
   npm install
   ```
2. Открыть папку `testWebbApp` в VS Code.
3. Открыть чат, в Session Target выбрать **Copilot**, в списке агентов выбрать **WebApp Tester**.
4. Отправить запрос, например: `Протестируй кнопку "Забыли пароль?"` или `Протестируй приложение в текущей папке`.

Агент сам определяет команду запуска и порт, при необходимости запускает сервер и останавливает его после теста, если запустил сам.

Результат: короткое сообщение в чате и файл `reports/test-report-YYYY-MM-DD-HHMM.md`.

## Использование в другом проекте

Скопировать в проект файл агента в `.github/agents/` и файл `.mcp.json`.

## Формат отчёта

Сводка (дата, адрес, число проблем по уровням Critical / Major / Minor / Info), затем блоки по каждому багу: шаги воспроизведения, ожидаемое и фактическое, место проблемы, скриншот или лог, рекомендация. В конце: «Что работает корректно», «Не проверено», «Общие рекомендации».

## Ограничения

- Тестируются только localhost, тренировочные сайты и ресурсы, разрешённые пользователем.
- Файлы проекта агент не редактирует (создаёт только отчёт и скриншоты в `reports/`); запрет задан инструкциями, а не технически.
- Необратимые действия (удаление данных, платежи, отправка писем) выполняются только после вопроса пользователю.
- За один прогон проверяется не более 15 сценариев.
- Результат зависит от выбранной модели, тексты отчётов нужно просматривать.

## Пример результата

На тестовом приложении агент нашёл ошибку уровня Major: ссылка «Забыли пароль?» ведёт на страницу 404 (`Cannot GET /forgot-password`). Отчёт: `reports/test-report-2026-10-17-0249.md`.
